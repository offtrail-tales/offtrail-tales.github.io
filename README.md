# Offtrail Tales

Offtrail Tales plays interactive stories written in
[ink](https://www.inklestudios.com/ink/), with pictures, music, sound and
video. Play it at <https://offtrail-tales.github.io/>.

This repository holds the built web app only: the files in `site/` are what
GitHub Pages serves. Each update replaces the repository in full, so it
holds the current version and no history. The source code lives in a
separate repository.

## Privacy

The app runs entirely in your browser. There is no server code, no account
and no tracking. Tales you import, your saves and your settings stay in your
browser, and the page's security policy blocks requests to any other
address.
