Features & Comparison

Offtrail Tales is a free browser-based editor and player for choice-based interactive fiction with media, powered by ink. This page explains how it works and how it compares to other tools. Last updated November 2026.

▶ Watch the walkthrough on YouTube

What Offtrail Tales does

Architecture

The player, the editor and the tale are three independent modules. The tale is the author's product: a portable file with a complete technical specification. The player reads it, the editor writes it, and .otproject keeps the source separate from the distributed .tale. The author cares about the tale. The rest is infrastructure.

Purpose-built for this one job, it is more capable and easier to use than tools that try to be general-purpose game engines. In this space, no other tool separates player, editor and tale this way. Other tools bake the story into its own player, publish through a platform, or hand the author a raw file with no player at all. The author ends up building menus, save systems and output formats instead of writing the story, and the result rarely works well on both a phone and a computer.

I built it free from registration, app stores and business models, which makes it that much easier to pick up and use. Nothing is uploaded, all data lives on the user's machine, and the build ships with a full security policy.

Player app

  • Browser-based, works on phones and computers. No install.
  • Title screen, tale library, saves (autosave + manual), settings.
  • Three colour themes. Tales can bring their own.
  • Music (looping, crossfade), sound effects, video (skippable).
  • Backgrounds, inline pictures (six frame styles), zoomable maps.
  • Speech formatting, text input with optional keypad.
  • Timed pauses.
  • Player app loads in under 250 KB of code. Tales load on demand.

Editor

  • Browser-based (best on a computer). No install, no account.
  • Ink syntax highlighting, folding, problem checking.
  • Live preview: exactly what the player sees, replays your choices on edit.
  • Story map: visual graph of scenes and choices.
  • Drag-and-drop media with automatic conversion (AVIF, M4A, MP4).
  • Theme tab: six-colour palette, contrast checking, background picture.
  • Multiple ink files, insert toolbar, templates, worked example.
  • Each browser tab holds its own tale (Web Locks).
  • Publish runs 50 random playthroughs before building the .tale.
  • Editor loads in under 750 KB of code. Media conversion loads on demand.

File formats

  • .otproject: the source (ZIP of .ink files, media, tale.json). Reopen in the editor or unzip and use Inky. Spec.
  • .tale: the compiled tale for players (ZIP of compiled ink JSON + media, hash-verified). Data only, no code. Spec.
  • Standard ink throughout. Every media tag is a standard ink tag Inky silently ignores. No lock-in.

Both formats are documented, open, and versioned.

Privacy and cost

  • No account, no login, no tracking, no ads.
  • Everything stays on the device. Nothing is uploaded.
  • Free. MIT-licensed. No business model.

Twine

The most widely used IF authoring tool. Visual node editor with passages connected by links. Multiple story formats (Harlowe, SugarCube, Chapbook). Exports standalone HTML files.

vs. Offtrail Tales: Each Twine story bakes the player into the HTML. No shared player, no tale library, no saves across stories. Media is possible but manual: you embed it in HTML yourself, with no conversion pipeline or media tags. Output is generally not optimized for phones. Offtrail Tales separates story from player, treats media as first-class, and one app plays any tale.

Inky

inkle's own editor for ink. Desktop app (Electron). Syntax highlighting, preview panel, error checking. The reference implementation.

vs. Offtrail Tales: Inky is desktop-only, text-only, and exports a JSON file with a bare HTML template you style and host yourself. No media support, no shared player, no mobile-friendly output. Offtrail Tales is the browser editor and player that picks up where Inky stops: same ink language, but with media, themes, a shared player, and .tale files ready to share.

ChoiceScript

Choice of Games' scripting language for choice-based fiction. Text-heavy, stat-driven. CSIDE is the community-built editor. Commercial publication through Choice of Games or Hosted Games.

vs. Offtrail Tales: Text-only (cover images only). Commercial use requires publishing through Choice of Games. No media support. Offtrail Tales is fully open (MIT), with native media and no publishing gatekeep.

Inform 7

A natural-language programming system for parser-based interactive fiction. Desktop IDE. Compiles to Z-machine or Glulx. The standard for parser IF.

vs. Offtrail Tales: Parser IF (typed commands), entirely different genre. Desktop-only. Offtrail Tales is choice-based with media, browser-only.

Adventuron

A browser-based IDE for retro-style text adventures. Code editor with preview panel, pixel art support, music. Primarily parser-based with experimental choice support. Games publish to itch.io.

vs. Offtrail Tales: Primarily parser-based with a retro aesthetic. Offtrail Tales is choice-based with modern media (photos, audio, video, maps) and a mobile-first player.

Ink-based

Atrament

A modular developer toolkit for building ink games. Includes saves (autosave, checkpoints, slots), rich text markup, overlays, themes, images, audio, video, and a debugger. Exports standalone HTML, PWA, desktop apps and Android.

vs. Offtrail Tales: Atrament is a library you build your own app around. It has no editor. You write ink in VS Code, configure JSON, and run npm scripts. Offtrail Tales is the finished app and editor: open the browser, write, preview, publish.

Moving Literature

No-code browser tool for IF built on ink, with images and Lottie animations triggered by ink tags. Funded by a 2025 IFTF micro-grant.

vs. Offtrail Tales: Also ink-based and browser-based, but no audio, video or maps. No dedicated player app or tale format: stories are published as web pages. Offtrail Tales has full media support, a shared player, and portable .tale files.

inFict

A platform for Twine, Ink or Inform stories connected to real-world channels: texts, calls, email, GPS triggers, multiplayer. Invite-only beta.

vs. Offtrail Tales: Different goal entirely. inFict bridges IF into real-world interaction. Offtrail Tales stays on-screen with native media support.

Choice-based (not ink)

Kinexus

A browser-based, no-code visual editor. Scenes with images and audio, a tree view, built-in player, export to ZIP for itch.io. Chrome only.

vs. Offtrail Tales: No conditionals or variables. Stories cannot branch on state. Not ink, so work is not portable. Offtrail Tales has full ink logic, media as first-class tags, and works in any browser.

Narrat

A game engine for narrative games with RPG features: skill checks, inventory, quests, character portraits. Own scripting syntax. Exports for web and PC (Steam).

vs. Offtrail Tales: An RPG engine with game mechanics. Requires CLI project setup (npm). Offtrail Tales focuses on pure choice-based fiction with media, runs entirely in the browser.

Storyfall

An authoring tool and publishing marketplace. Writers sell directly to readers, platform charges fees via Stripe.

vs. Offtrail Tales: A marketplace with accounts and payment processing. Offtrail Tales has no platform, no account, no fees. You keep and distribute your files however you choose.

ChosenPath.ai

AI generates story environments from a premise. Single and multiplayer.

vs. Offtrail Tales: AI-driven content generation. Offtrail Tales is author-written. No AI runs in the app or editor.

Other paradigms

Bardic

A Python-first IF engine. .bard files (ink-inspired syntax) compile to JSON. VS Code extension. Bundles for itch.io via Pyodide (full Python runtime in the browser). MIT-licensed.

vs. Offtrail Tales: Requires Python, a CLI and VS Code. Offtrail Tales runs entirely in the browser with no install.

Rez

A declarative language, compiler and runtime for HTML-based IF. Scenes and cards, inventory, factions, NPCs, behaviour trees. Assets (images, sounds, video) managed automatically. Open-source.

vs. Offtrail Tales: A full game-engine language with RPG systems. Requires a compiler and coding. Offtrail Tales is browser-only, choice-based with media, no install.

Etherground

A narrative engine with a browser node editor. Branching, inventory, handouts, word-swapping mechanic. Inspired by tabletop RPGs. Beta.

vs. Offtrail Tales: Still in beta with no theming or media pipeline. Offtrail Tales is a finished, shipped editor and player.

ChronicleHub

A quality-based narrative engine (StoryNexus-style). Custom "ScribeScript" syntax. Whitelist-only beta.

vs. Offtrail Tales: QBN (storylets gated by state) is a different narrative model from linear-spine choice-based fiction.

Quest Viva 6.0

Updated Quest, parser-based (typed commands), cross-platform.

vs. Offtrail Tales: Parser IF. Different genre entirely.

Liminal

A browser-based player for Twine HTML, Z-code, Glulx, ChoiceScript and Dialog formats. In development. No editor.

vs. Offtrail Tales: Multi-format player, but no editor and no portable media-rich tale format. Offtrail Tales is both the editor and the player, purpose-built for one format with full media.

Scribarchy

Browser-based multiplayer collaborative IF. Players explore or build multiverses from public-domain works. Also a play-by-post RPG platform.

vs. Offtrail Tales: Multiplayer and collaborative, text only. Offtrail Tales is single-author, single-player with rich media.
